# دعوة فرح عبدالله & منار

موقع static (HTML و CSS و JS من غير build) فبيترفع على أي استضافة.

## ١. عدّل البيانات
كل حاجة في `js/config.js`: تاريخ الفرح ووقته، القاعة والعنوان، لينك اللوكيشن، آخر ميعاد للرد، ورقمك على واتساب.
واتأكد كمان من تاريخ كتب الكتاب `katbDateText` (أنا أخدته من تاريخ الكاميرا).

## ٢. معاينة على جهازك
```bash
npx serve .
```
وافتح `http://localhost:3000/?to=أستاذ محمد&n=3`

## ٣. الرفع على Coolify
1. New Resource → Public/Private Repository → اختار الـ repo
2. Build Pack: **Dockerfile** (الـ Dockerfile بيشغل nginx على بورت 80)
3. Ports Exposes: `80` وحط الدومين وفعّل HTTPS
4. Deploy

تجربة الـ image على جهازك:
```bash
docker build -t wedding-card . && docker run --rm -p 8080:80 wedding-card
```

بعد الرفع:
1. غيّر `YOUR-DOMAIN` في `index.html` (في وسم `og:image`) للينك الموقع، عشان صورة المعاينة تظهر في واتساب
2. حط نفس اللينك في `siteUrl` في `config.js`

## ٤. لينكات الضيوف
افتح `/links.html` واكتب الأسماء (كل اسم في سطر، ولو عاوز تحدد عدد أفراد اكتب `الاسم|3`).
هتطلعلك لينكات جاهزة ومعاها زرار واتساب لكل ضيف.
الضيف هيلاقي اسمه على الظرف وفي أول الموقع، ومكتوب جاهز في فورم تأكيد الحضور.

## ٥. تأكيد الحضور ورسمة القاعة والتهاني
- **من غير إعداد:** لو `rsvpEndpoint` فاضي، الرد بيتبعتلك رسالة واتساب على `whatsappNumber`. رسمة القاعة بتظهر بس من غير عداد، ودفتر التهاني بيبقى مخفي
- **مع Google Sheet:** اتبع الخطوات اللي في أول `rsvp/google-apps-script.js` وحط اللينك في `rsvpEndpoint`. ساعتها:
  - العداد بيتحسب من الردود الحقيقية (آخر رد لكل ضيف)، من `capacity` في `config.js`
  - الكراسي بتنور دهبي من قدام لورا، وكرسي الضيف بينور أزرق لما يحجز
  - التهاني (ومعاها الكلمة اللي في فورم الحضور) بتظهر للكل
  - **عشان تخفي تهنئة:** علّم على خانة "إخفاء" في الشيت، وهتختفي خلال دقيقة

## ٦. الموسيقى
حط ملف mp3 في `audio/music.mp3`. بيشتغل لما الضيف يفتح الظرف، ولو مفيش ملف الزرار بيختفي لوحده.

## الملفات
```
index.html                 الموقع
links.html                 مولد لينكات الضيوف (مش ظاهر للضيوف)
js/config.js               ← البيانات اللي هتعدلها
js/main.js                 الظرف والعد التنازلي والتقويم والـ RSVP والمعرض
css/style.css
images/                    صور مختارة ومضغوطة من كتب الكتاب (+ og.jpg لمعاينة واتساب)
rsvp/google-apps-script.js
```
